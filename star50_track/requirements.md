# 飞书科创50行情推送机器人 —— 需求规格说明书

## 1. 项目概述

构建一套自动化行情推送系统，每个交易日通过飞书机器人推送科创50指数及关联基金的行情汇总与分析，支持后续扩展至其他指数。

## 2. 功能需求

### 2.1 推送任务 A —— 14:45 科创50盘中快报

| 项目 | 说明 |
|------|------|
| 触发时间 | 每个交易日 14:45（北京时间） |
| 接收渠道 | 飞书群（通过飞书开放平台应用 IM API） |
| 消息格式 | 飞书卡片消息（`interactive`） |
| 数据时点 | 14:40 实时快照 |

**卡片内容结构：**

1. **标题栏** — "科创50 盘中快报"，背景色随涨跌变化（红涨绿跌）
2. **涨跌幅大字号显示** — 当日涨跌百分比，精确到小数点后两位
3. **趋势摘要** — 14:40 时点处于上涨/下跌趋势，附带开盘价、最高价、最低价
4. **市场观点汇总** — 结构化归纳如下：
   - 东方财富机构观点（最近 3-5 条）
   - 雪球/同花顺热门分析摘要
   - 结论格式：「近期 X 家看多 / Y 家看空 / Z 家中性」，附来源链接
5. **风险提示** — "以上为市场观点汇总，不构成投资建议"

### 2.2 推送任务 B —— 17:30 基金收盘总结

| 项目 | 说明 |
|------|------|
| 触发时间 | 每个交易日 17:30（北京时间） |
| 接收渠道 | 飞书群 |
| 消息格式 | 飞书卡片消息（`interactive`） |

**卡片内容结构：**

1. **标题栏** — "基金 011609 收盘总结"，背景色随净值变动方向
2. **基金净值变动** — 当日涨跌幅、单位净值、估算净值
3. **科创50收盘总结** — 收盘价、涨跌幅、成交额
4. **市场观点汇总** — 同任务 A 的分析汇总格式

### 2.3 交易日历校验

- 脚本内置 A 股交易日历逻辑，非交易日自动跳过
- 节假日、周末不发送消息

## 3. 非功能需求

### 3.1 可靠性

- **调度载体**: GitHub Actions，cron 定时触发
  - 14:45 → UTC 06:45
  - 17:30 → UTC 09:30
- 不依赖本地电脑开机，云端执行
- 执行失败时 GitHub Actions 自带重试 + 邮件通知

### 3.2 数据准确性

- 行情数据来源：东方财富公开 JSON 接口（`push2.eastmoney.com`）
- 数据结构化拉取，无 HTML 解析，消除解析错误
- 科创50 指数代码：`1.000688`
- 基金代码：`011609`

### 3.3 可验证性

- 每条市场观点附带原始来源链接，点击即可追溯验证
- 不使用无来源的 AI 生成判断作为建议
- 输出格式为"观点汇总"而非"操作指令"

### 3.4 扩展性

- 配置驱动架构，单脚本 + YAML 配置文件
- 新增跟踪指数只需在 `config.yaml` 中添加一行配置
- 示例配置结构：

```yaml
indices:
  - id: "kc50"
    code: "1.000688"
    name: "科创50"
    schedule: "14:45"
    feishu_chat_id: "oc_xxx"

funds:
  - id: "011609"
    code: "011609"
    name: "某某基金"
    related_index: "kc50"
    schedule: "17:30"
    feishu_chat_id: "oc_xxx"
```

### 3.5 安全性

- 飞书 App ID、App Secret 存储在 GitHub Actions Secrets 中
- 不在代码中硬编码任何凭证
- `tenant_access_token` 运行时获取，不持久化

## 4. 技术架构

```
GitHub Actions (cron)
    │
    ├── task_a.py (UTC 06:45 触发)
    │     ├── 交易日判断 (A股日历)
    │     ├── 东方财富行情接口 → 科创50 14:40 快照
    │     ├── 东方财富/雪球/同花顺 → 机构观点+热点分析
    │     ├── 大模型归纳 → 结构化观点汇总
    │     ├── 飞书 OAuth → tenant_access_token
    │     └── 飞书 IM API → 发送卡片消息
    │
    └── task_b.py (UTC 09:30 触发)
          ├── 交易日判断
          ├── 东方财富行情接口 → 科创50收盘 + 011609净值
          ├── 市场观点汇总 (同 task_a)
          ├── 飞书 OAuth
          └── 飞书 IM API → 发送卡片消息
```

## 5. 数据源明细

| 用途 | 接口/来源 | 格式 |
|------|----------|------|
| 科创50实时行情 | `push2.eastmoney.com/api/qt/stock/get` | JSON |
| 基金011609净值 | 东方财富基金接口 | JSON |
| 机构观点 | 东方财富个股/指数新闻板块 | HTML → 文本提取 |
| 社区分析 | 雪球/同花顺热门 | HTML → 文本提取 |
| 观点归纳 | 大模型 API (DeepSeek/OpenAI) | API |
| 交易日历 | 内置本地日历数据 | Python 计算 |

## 6. 视觉颜色语义

- A 股语境：红涨绿跌
- 卡片标题栏背景色：上涨 `#E53935`，下跌 `#43A047`
- 涨跌幅数字：上涨红色 `#D32F2F`，下跌绿色 `#388E3C`

## 8. 风险与应对

| 风险 | 应对措施 |
|------|---------|
| GitHub Actions 执行时间波动（±5 min） | 14:45 卡片标明"数据时点 14:40"，即使用户略晚收到数据依然是 14:40 快照 |
| 东方财富接口变更 | 行情接口多年稳定；观点抓取部分使用 CSS 选择器 + 备用正则，降低耦合 |
| 雪球/同花顺反爬 | User-Agent + 请求频率控制 + 数据缓存；极端情况降级为仅东方财富来源 |
| 飞书 token 过期 | token 有效期 2 小时，每次运行时重新获取，不过期 |
| 非交易日误触发 | 脚本第一步校验交易日历，holiday 直接 exit 0 |
